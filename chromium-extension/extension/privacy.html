SHERLOQ

Confidentialité

27 octobre 2026 · Extension 0.5.4

L’éditeur ne collecte ni vos images, ni vos PDF, ni les textes reconnus par l’OCR, ni de données sur votre utilisation de l’extension. SHERLOQ traite les images, les PDF et les images vidéo que vous choisissez ; les calculs de la loupe et de l’OCR s’exécutent sur votre ordinateur. L’extension n’intègre aucun dispositif de suivi.

Contenu utilisé

Après activation ou une commande sur une image, l’extension lit les images et leurs liens dans la page pour rechercher une définition supérieure. Elle peut préparer les images voisines. Elle conserve les fichiers utiles, leurs dimensions, leurs adresses et leur provenance. Elle ne constitue pas un historique général de navigation.

Connexions

La recherche des images peut contacter les sites qui les hébergent. Le navigateur peut utiliser votre session sur ces sites pour obtenir les fichiers. Les ressources de calcul manquantes sont téléchargées depuis GitHub ; GitHub reçoit alors une requête de téléchargement, avec les informations réseau habituelles. Vos images et le texte OCR ne sont pas envoyés à GitHub pour analyse.

L’OCR est facultatif. S’il manque des poids, l’extension affiche leur taille et attend votre validation avant de les télécharger. La lecture des PDF et la détection géométrique de leurs sous-images utilisent le code fourni avec l’extension, sans téléchargement de modèle.

Bibliothèques SHERLOQ

L’extension recherche d’abord les ressources disponibles dans la version locale que vous avez configurée, puis dans SHERLOQ web au sein du même profil de navigateur. Cela peut ouvrir temporairement un onglet SHERLOQ en arrière-plan. Les ressources déjà présentes sont lues sur place et vérifiées. Un dossier de calcul n’est accessible que si vous en avez déjà donné l’autorisation à SHERLOQ web. Les nouveaux téléchargements peuvent être conservés dans le cache de SHERLOQ web pour être réutilisés.

Web, local et presse-papier

Les commandes Web et Local remettent les fichiers choisis à l’application SHERLOQ configurée dans les réglages. Depuis le lecteur PDF, elles remettent le PDF d’origine. L’application destinataire a son propre fonctionnement et sa propre politique de confidentialité. Utilisez une adresse HTTPS pour une destination web publique.

Après une commande OCR, le texte reconnu est écrit dans votre presse-papier. L’extension ne lit pas son contenu. Les exports d’images se font à votre demande.

Conservation et suppression

Les préférences, raccourcis, repères et découpes de sous-images sont conservés dans le profil du navigateur. Les découpes calculées sont réutilisées pour éviter de refaire la détection. Les fichiers temporaires sont nettoyés au démarrage, à la fermeture des onglets concernés et selon leur âge et le budget de stockage. Les fichiers d’un lecteur encore ouvert et ceux en cours de transfert sont conservés pour cet usage. Le bouton « Supprimer les images temporaires » des réglages efface les fichiers temporaires et le cache des découpes PDF. Les découpes conservées avec une image de la sélection restent liées à cette image.

Les images ajoutées à la sélection restent jusqu’à leur retrait dans la sélection. Les modèles téléchargés restent dans le cache qui les accueille. La désinstallation supprime les données propres à l’extension ; elle ne supprime pas vos exports, le presse-papier, les données de SHERLOQ web ou les fichiers de votre version locale. Ces éléments se gèrent depuis leur application ou leur emplacement respectif.

Mesure d’audience et publicité

L’extension n’intègre ni publicité, ni mesure d’audience, ni vente de données. Les données traitées servent aux fonctions décrites ici.

Code et contact

Le projet et ses licences sont accessibles sur GitHub. Les coordonnées de l’éditeur figurent sur la fiche de l’extension dans le Store.

Privacy

27 October 2026 · Extension 0.5.4

The publisher does not collect your images, PDFs, OCR text or information about your use of the extension. SHERLOQ processes the images, PDFs and video frames you choose; magnifier and OCR calculations run on your computer. The extension includes no tracking.

Content used

After activation or an image command, the extension reads images and their links in the page to look for a higher resolution. It may prepare nearby images. It stores the files needed, their dimensions, addresses and provenance. It does not build a general browsing history.

Connections

Finding images may contact the sites hosting them. The browser may use your session on these sites to retrieve the files. Missing calculation resources are downloaded from GitHub; GitHub receives a download request and the usual network information. Your images and OCR text are not sent to GitHub for analysis.

OCR is optional. When model files are missing, the extension displays the download size and waits for your confirmation. Reading PDFs and geometrically detecting their sub-images use code included with the extension, without a model download.

SHERLOQ libraries

The extension first checks resources in the local version you configured, then in SHERLOQ web in the same browser profile. This may temporarily open a background SHERLOQ tab. Existing resources are read in place and verified. A calculation folder is only accessible if you previously authorized SHERLOQ web to use it. New downloads may be saved in the SHERLOQ web cache for reuse.

Web, local and clipboard

The Web and Local commands hand the selected files to the SHERLOQ application configured in settings. From the PDF reader, they hand over the original PDF. The receiving application has its own behavior and privacy policy. Use an HTTPS address for a public web destination.

After an OCR command, the recognized text is written to your clipboard. The extension does not read the clipboard. Image exports happen at your request.

Retention and deletion

Preferences, shortcuts, bookmarks and sub-image boundaries are saved in the browser profile. Calculated boundaries are reused to avoid repeating detection. Temporary files are cleaned at startup, when the relevant tabs close, and according to their age and storage budget. Files belonging to an open reader or an ongoing transfer are kept for that use. The “Delete temporary images” button in settings clears temporary files and the PDF boundary cache. Boundaries saved with an image in the selection remain attached to that image.

Images added to the selection stay until you remove them from the selection. Downloaded models remain in the cache holding them. Uninstalling removes the extension’s own data; it does not remove exported files, clipboard contents, SHERLOQ web data or your local version’s files. Manage these in their respective application or location.

Analytics and advertising

The extension contains no advertising, analytics or sale of data. Processed data serves the functions described here.

Code and contact

The project and its licenses are available on GitHub. Publisher contact details are provided on the extension’s Store listing.

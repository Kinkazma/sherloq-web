# Validation scope

## Web 0.25.0

Publication verifies that reconstruction preserves the supplied canonical sources, prepared interface files, executable runtime mirrors, optional model identities and the full eight-receipt ancestry. Locally served files are checked against their SHA-256 and size, including worker bundles and native modules. Source, mirror, lock, manifest and receipt changes are rejected when their recorded identities no longer agree.

The resource catalogue and local interface inventory include the cumulative changes. The previous local updater accepts these inventories and preserves explicitly excluded optional resources. Static dependency closure and transport checks are distinct from a fresh installation and reopening of the complete application with the network disconnected.

Functional validation comes from the supplied component and browser qualifications. It covers native source regions, independent windows and exclusions, PDF inspection, OCR selection, retained displays, bounded previews, worker ownership and partial exports. Those results keep their recorded input, browser and method scope. They are not a new scientific accuracy study or a guarantee for every device. An interrupted combined-analysis run does not establish a completed result for its unfinished branch. Preview latency remains dependent on the browser, image and available resources.

Native diagnostic filenames are normalized for publication. For the inherited modules, instruction sections remain byte-identical. The rebuilt SEEDS support retains the mathematical sources and arithmetic compiler options; its checked synthetic geometries preserve the corresponding labels. No model inference is repeated by these publication checks.

## Examples and model limitations

The gallery contains illustrative engine results rather than a performance or accuracy benchmark. Input dimensions and known edit references belong to each example. Scaled WebP previews are separate from detector preprocessing. The RITA/TruFor study retains its own protocol and image licence.

The experimental B-Free, SPAI and DTD tools retain their method-specific limitations. An image-wide AI score is not an authenticity confidence or a localization of partial edits. Spatial outputs from different methods do not share an interchangeable meaning. See the method documents, example captions and component notices.

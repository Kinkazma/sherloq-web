Serve over localhost/HTTPS with local JS/WASM assets. No runtime npm install or
CDN is required. The current OpenCV WASM module requires WebAssembly SIMD;
the recorded Chrome, Firefox and WebKit builds passed its qualification. M3 run cancellation first stops computation cooperatively and preserves completed
images; forced termination and other hard-cancel paths clear image state, reported
as `imagesCleared:true`. Reload retained original bytes after such a reset. Use one
engine per page so its jobs, pools and caches share a budget.

## Reproduce

```sh
npm ci --ignore-scripts
npm test
node scripts/browser-test.mjs --pixels --extended --frequency --frequency-lifecycle
# Optional Firefox/WebKit correctness run after installing pinned Playwright browsers:
# PLAYWRIGHT_BROWSERS_PATH=.build/playwright-browsers node scripts/browser-test.mjs --extended --browser=firefox
node scripts/browser-test.mjs --pipeline --benchmark --pools
node scripts/browser-test.mjs --quality-pool-test --quality-pool
node scripts/browser-test.mjs --frequency-benchmark
node scripts/browser-test.mjs --double-jpeg --ghost
node scripts/browser-test.mjs --ghost-benchmark
node scripts/browser-test.mjs --zero
node scripts/browser-test.mjs --zero-memory --zero-benchmark
node scripts/browser-test.mjs --contrast --stereo

node scripts/browser-test.mjs --prnu-memory --prnu-benchmark
```

Browser tests use an installed Google Chrome through Playwright, with an isolated
headless session and a temporary localhost server. No profile/credential access.
Benchmark runs are small and bounded; coordinate them with other local workloads.
Cold means a new engine/worker, not a flushed OS/driver cache. Browser rendering,
full-pipeline and isolated-kernel measurements are explicitly distinguished.

To regenerate native fixtures, run `scripts/generate-reference.py` and
`scripts/generate-codec-reference.py`, plus `scripts/generate-pixel-reference.py`, with the native reference Python environment
(OpenCV 4.11.0, NumPy and the SHERLOQ source checkout). They generate arithmetic
patterns/noise and never read private images. `scripts/inventory.py` performs a
static source and local weight-presence inventory without model execution.

To rebuild JPEG, install Emscripten **4.0.15** in a build directory, set `EMSDK`,
and run `bash scripts/build-jpeg.sh`. It verifies the libjpeg-turbo **3.0.3** source
archive hash before building. SDK/cache/build logs under `.build/` are excluded.
OpenCV/contrib 4.11.0 rebuild via `bash scripts/build-opencv.sh`; hash-wasm 4.12.0
bundles via `node scripts/build-hashes.mjs`. PyWavelets 1.5.0 rebuilds via
`bash scripts/build-pywt.sh`. Sources, licenses and version hashes
are pinned. Refresh the runtime manifest only after testing: `node scripts/runtime-manifest.mjs`.

Classic ELA is a recompression visualization. Energy is a separate descriptive
analysis. Legacy biomes, Ghost corroboration within biomes and learned
model masks remain unavailable. EXIF JPEG and documented PNG/TIFF subsets are
qualified; unsupported encodings fail explicitly. GPU integer lookup
has exact synthetic proof but is not selected automatically: CPU is faster in
its measured transfer-inclusive comparison. See notices and GPL-3.0 license.

Frequency smoothing has a offline-qualified WebGPU path with CPU override,
shared memory admission and exact recorded masks/outputs. Its full-pipeline gain
is measured separately from the rejected ELA GPU lookup. See FREQUENCY-ENGINE.md.

ZERO retains its separate AGPL-3.0-or-later license and corresponding source; see
NOTICE.md. It supports original-order CPU, qualified optimized CPU, immediate bounded
workers, five views and typed NPZ export. `workerEngine.exportResult()` serializes
large supported exports under the shared budget without blocking the page thread.

Noisesniffer: see [the CPU engine contract and measured limits](docs/NOISESNIFFER.md).
